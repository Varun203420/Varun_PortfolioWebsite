# Varun Hariharan — Portfolio

Next.js 14 (App Router) + Tailwind. Design direction: ink/paper palette,
Space Grotesk + Inter, hairline borders, sharp corners — built around the
Monte Carlo fan-chart motif rather than a generic AI-portfolio look.

## Run locally
npm install
npm run dev

## Deploy
Push to GitHub, import the repo on vercel.com — zero config needed,
Next.js is auto-detected.
